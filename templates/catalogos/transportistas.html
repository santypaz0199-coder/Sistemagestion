Como funciona el seguimiento

El link de seguimiento se construye automaticamente asi:

  • Si la URL base termina en / → se agrega la guia directo: https://ejemplo.com/track/123456
  • Si la URL base NO termina en / → tambien se agrega: https://ejemplo.com/track/123456
  • Si la URL contiene {guia} → se reemplaza: https://ejemplo.com/track/{guia} → https://ejemplo.com/track/123456
